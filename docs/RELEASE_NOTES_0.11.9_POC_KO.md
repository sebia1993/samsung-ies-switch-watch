# Samsung Switch Watch 0.11.9-poc 릴리스 노트

릴리스 날짜: 2026-08-12

`0.11.9-poc`는 장비 모델 선택을 사용자의 판단에서 제거하고, 실제 장비 응답으로 안전하게
판별하는 사용성 릴리스입니다. Agent API v4 요청, Viewer 장비 저장 형식, 자격 증명 보호,
수동 명령과 주기 감시 흐름은 유지합니다.

## 장비 모델 자동 판별

- 새 장비의 모델 필드는 읽기 전용 `확인 대기`로 시작합니다.
- `로그인 확인`은 Telnet 인증과 선택적 enable 전환을 마친 뒤 `show version`을 한 번만
  실행합니다.
- 출력에서 IES4224GP, IES4028XP, IES4226XP 중 정확히 하나가 확인될 때만 정규화된 모델명을
  Viewer에 반환합니다.
- 판별에 사용한 `show version` 원문은 Viewer 응답, 설정 파일, 이벤트 또는 Agent 로그에
  저장하지 않습니다.
- 모델 판별이 성공해야 새 장비를 저장하고 주기 감시를 켤 수 있습니다.
- 기존 장비의 IP를 바꾸면 이전 판별 결과를 재사용하지 않고 다시 `확인 대기`로 전환하며
  주기 감시를 끕니다.

## 실패를 임의 추정하지 않는 규칙

- 지원 모델 토큰을 찾지 못하면 `MODEL_NOT_DETECTED`로 중단합니다.
- 둘 이상의 지원 모델 토큰이 함께 확인되면 `MODEL_AMBIGUOUS`로 중단합니다.
- 구형 Agent가 판별 결과를 제공하지 않으면 Viewer는 `MODEL_DETECTION_UNAVAILABLE`을 표시하고
  Agent와 Viewer를 같은 최신 Release로 맞추도록 안내합니다.
- 어떤 실패에서도 첫 번째 모델이나 사용자가 이전에 선택한 모델을 자동 정답으로 간주하지
  않습니다.

## 호환성

- 기존 API v4 요청 경로와 요청 본문 필드는 변경하지 않습니다. `model` 요청값은 구형 계약을
  유지하기 위한 내부 bootstrap 값이며 사용자 선택값이 아닙니다.
- test 성공 응답에 선택적인 `detectedModel` 필드만 추가합니다. manual·monitor 응답과 명령
  결과 형식은 변경하지 않습니다.
- Viewer의 기존 장비 파일에 저장된 `Model` 필드와 DPAPI 자격 증명은 그대로 읽습니다.
- 기존 장비는 저장된 모델과 동일한 IP를 편집하는 동안 호환 동작을 유지하며, IP가 바뀌면
  재판별을 요구합니다.
- Agent 설치·복구, 방화벽, HTTPS, Viewer 연결, 대시보드와 데이터 저장 계약은 변경하지
  않습니다.

## 배포 파일

```text
SamsungSwitchWatch-Agent-0.11.9-poc-win-x64.zip
SamsungSwitchWatch-Viewer-0.11.9-poc-win-x64.zip
```

두 패키지는 코드 서명되지 않은 POC입니다. 공식 Release의 SHA-256을 확인하고 사내
SmartScreen, EDR, AppLocker와 WDAC 승인 절차를 따르십시오.

## 검증 범위와 현장 한계

- 합성 Telnet 세션으로 정확한 모델, 미확인 모델, 다중 모델, 빈 출력과 대소문자 변형을
  검증합니다.
- Agent test 목적이 `show version`을 정확히 한 번 실행하고 원문을 응답하지 않는지 검증합니다.
- Viewer가 자동 판별 전 저장을 막고, 성공 뒤 모델을 표시하며, IP 변경과 구형 Agent 응답을
  안전하게 처리하는지 WPF·단위 테스트로 검증합니다.
- 개발 환경의 Mock·fixture는 실제 삼성 스위치가 `show version`에 어떤 문자열을 출력하는지
  증명하지 않습니다.
- 현장에서는 영향이 적은 스위치 한 대씩 `로그인 확인`을 실행해 자동 판별 모델과 장비 전면
  모델명이 일치하는지 확인한 뒤 포트·로그 수집을 시험해야 합니다.
